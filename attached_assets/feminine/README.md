# Feminine Collection Logos

Pearl-detailed and feminine-leaning crests for the Feminine Collection (`/feminine`)
and the "Feminine Collection" filter in logo pickers.

Pink, purple, and other feminine colorways from the circular Canvas Collection
also live in this folder so they stay easy to find when picking by gender —
Canvas circles stay registered under **Canvas Collection**; pearl griffin crests
are registered under **Badge of Honor** (Royalty Badge of Honor · Female Logos).
